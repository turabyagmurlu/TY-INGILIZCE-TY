=== it1-2 [grammar] Gramer: essere (olmak)
intro: İtalyancada 'olmak' fiili essere'dir. Özneye göre değişir.
rule: io <b>sono</b>, tu <b>sei</b>, lui/lei <b>è</b>, noi <b>siamo</b>, voi <b>siete</b>, loro <b>sono</b>. Örnek: "Io <b>sono</b> felice" = "Ben mutluyum".
structure: [["Özne","Fiil","Örnek"],["io (ben)","sono","Io sono Deniz"],["tu (sen)","sei","Tu sei gentile"],["lui/lei (o)","è","Lei è felice"],["noi (biz)","siamo","Noi siamo qui"],["voi (siz)","siete","Voi siete pronti"],["loro (onlar)","sono","Loro sono qui"]]
  ex: Io sono Deniz. = Ben Deniz'im.
  ex: Tu sei gentile. = Sen naziksin.
  ex: Lei è felice. = O mutlu.
  ex: Noi siamo qui. = Biz buradayız.
  Q1: Io ___ Deniz. [sono / sei / è] -> sono :: io ile 'sono'.
  Q2: Tu ___ gentile. [sei / sono / è] -> sei :: tu ile 'sei'.
  Q3: Lei ___ felice. [è / sei / sono] -> è :: lui/lei ile 'è'.
  Q4: Noi ___ qui. [siamo / siete / sono] -> siamo :: noi ile 'siamo'.
  Q5: Voi ___ pronti. [siete / siamo / sono] -> siete :: voi ile 'siete'.
  Q6: Loro ___ qui. [sono / siete / è] -> sono :: loro ile 'sono' (io ile aynı).
  Q7: Ben Türküm (kadın): Io ___ turca. [sono / è / sei] -> sono :: io ile 'sono'. Kadın için 'turca'.

=== it1-4 [grammar] Gramer: Belirli artikeller (il / la)
intro: İtalyancada isimlerin cinsiyeti vardır: eril ve dişil. Artikel buna göre değişir.
rule: Eril tekil: genelde <b>il</b> (il libro = kitap). Dişil tekil: <b>la</b> (la casa = ev). Sesli harfle başlayan isimden önce <b>l'</b> (l'amico).
structure: [["Tür","Artikel","Örnek"],["Eril","il","il libro (kitap)"],["Dişil","la","la casa (ev)"],["Sesli ile başlayan","l'","l'amico (arkadaş)"]]
  ex: il libro = kitap
  ex: la casa = ev
  ex: la pizza = pizza
  ex: il caffè = kahve
  Q1: ___ libro (eril) [il / la / lo] -> il :: Eril tekil: il.
  Q2: ___ casa (dişil) [la / il / lo] -> la :: Dişil tekil: la.
  Q3: ___ pizza (dişil) [la / il / le] -> la :: pizza dişil: la pizza.
  Q4: ___ caffè (eril) [il / la / le] -> il :: caffè eril: il caffè.
  Q5: ___ amico [l' / il / la] -> l' :: Sesli harfle başlayan isimden önce l': l'amico.
  Q6: ___ finestra (dişil) [la / il / l'] -> la :: Dişil tekil: la finestra.
  Q7: ___ acqua (dişil, sesli harfle başlıyor) [l' / la / il] -> l' :: Sesli harften önce la → l': l'acqua.

=== it1-7 [grammar] Gramer: avere (sahip olmak)
intro: 'Sahip olmak' fiili: avere. 'Bir ...'m var' demek için kullanılır.
rule: io <b>ho</b>, tu <b>hai</b>, lui/lei <b>ha</b>, noi <b>abbiamo</b>, voi <b>avete</b>, loro <b>hanno</b>. Örnek: "Io <b>ho</b> un cane" = "Bir köpeğim var".
structure: [["Özne","Fiil","Örnek"],["io","ho","Io ho un libro"],["tu","hai","Tu hai una casa"],["lui/lei","ha","Lei ha un gatto"],["noi","abbiamo","Noi abbiamo tempo"],["voi","avete","Voi avete ragione"],["loro","hanno","Loro hanno fame"]]
  ex: Io ho un cane. = Bir köpeğim var.
  ex: Lei ha un gatto. = Onun bir kedisi var.
  ex: Noi abbiamo tempo. = Zamanımız var.
  ex: Loro hanno fame. = Onlar aç.
  Q1: Io ___ un libro. [ho / hai / ha] -> ho :: io ile 'ho'.
  Q2: Tu ___ una casa. [hai / ho / ha] -> hai :: tu ile 'hai'.
  Q3: Lei ___ un gatto. [ha / hai / ho] -> ha :: lui/lei ile 'ha'.
  Q4: Noi ___ tempo. [abbiamo / avete / hanno] -> abbiamo :: noi ile 'abbiamo'.
  Q5: Voi ___ ragione. [avete / abbiamo / hanno] -> avete :: voi ile 'avete'.
  Q6: Loro ___ fame. [hanno / ha / avete] -> hanno :: loro ile 'hanno'. (h okunmaz: 'anno')
  Q7: Bir kız kardeşim var: ___ una sorella. [Ho / Ha / Hai] -> Ho :: io ile 'ho'. Özne (io) söylenmese de fiilden anlaşılır.

##### LEVEL 2 A1+ Seviye 2 — Temel

=== it2-1 [grammar] Gramer: Çoğullar
intro: İtalyancada çoğul, ismin son harfine göre değişir.
rule: Eril <b>-o → -i</b>: libro → libri. Dişil <b>-a → -e</b>: casa → case. <b>-e</b> ile bitenler → <b>-i</b>: cane → cani.
structure: [["Tekil","Çoğul"],["libro (kitap)","libri"],["casa (ev)","case"],["cane (köpek)","cani"],["mela (elma)","mele"]]
  ex: due libri = iki kitap
  ex: tre case = üç ev
  ex: due cani = iki köpek
  Q1: un libro, due ___ [libri / libro / libre] -> libri :: Eril -o → -i.
  Q2: una casa, due ___ [case / casi / casa] -> case :: Dişil -a → -e.
  Q3: un cane, due ___ [cani / cane / canes] -> cani :: -e → -i.
  Q4: una mela, due ___ [mele / meli / mela] -> mele :: Dişil -a → -e.
  Q5: una sedia, due ___ [sedie / sedii / sedia] -> sedie :: Dişil -a → -e: sedie.
  Q6: un letto, due ___ [letti / lette / letto] -> letti :: Eril -o → -i: letti.
  Q7: un fiore, tre ___ [fiori / fiore / fiora] -> fiori :: -e ile biten → -i: fiori.

=== it2-3 [grammar] Gramer: Şimdiki zaman (-are fiilleri)
intro: -are ile biten fiiller düzenli çekilir. Örnek: parlare (konuşmak).
rule: Kök + <b>-o, -i, -a, -iamo, -ate, -ano</b>. parlare → io parlo, tu parli, lui/lei parla, noi parliamo, voi parlate, loro parlano.
structure: [["Özne","parlare"],["io","parlo"],["tu","parli"],["lui/lei","parla"],["noi","parliamo"],["voi","parlate"],["loro","parlano"]]
  ex: Io parlo italiano. = İtalyanca konuşurum.
  ex: Lei parla bene. = O iyi konuşur.
  ex: Noi mangiamo la pizza. = Pizza yeriz.
  Q1: Io ___ italiano. (parlare) [parlo / parli / parla] -> parlo :: io → -o: parlo.
  Q2: Tu ___ bene. (parlare) [parli / parlo / parla] -> parli :: tu → -i: parli.
  Q3: Lui ___ italiano. (parlare) [parla / parlo / parli] -> parla :: lui → -a: parla.
  Q4: Noi ___ la pizza. (mangiare) [mangiamo / mangiate / mangiano] -> mangiamo :: noi → -iamo.
  Q5: Voi ___ italiano. (parlare) [parlate / parliamo / parlano] -> parlate :: voi → -ate: parlate.
  Q6: Loro ___ molto. (lavorare) [lavorano / lavorate / lavora] -> lavorano :: loro → -ano: lavorano.
  Q7: Io ___ la TV. (guardare) [guardo / guarda / guardi] -> guardo :: io → -o: guardo.

=== it3-1 [grammar] Gramer: Geçmiş zaman — avere ile (passato prossimo)
intro: Geçmişte biten işler için passato prossimo. Çoğu fiil 'avere' + geçmiş ortaç ile kurulur.
rule: avere (ho/hai/ha/abbiamo/avete/hanno) + geçmiş ortaç. Ortaç: <b>-are→-ato</b>, <b>-ere→-uto</b>, <b>-ire→-ito</b>. "Ho mangiato" = "yedim".
structure: [["Mastar","Ortaç"],["parlare","parlato"],["mangiare","mangiato"],["credere","creduto"],["dormire","dormito"]]
  ex: Ho mangiato la pizza. = Pizza yedim.
  ex: Hai parlato con Deniz? = Deniz'le konuştun mu?
  ex: Abbiamo dormito bene. = İyi uyuduk.
  Q1: Yedim: Ho ___ (mangiare). [mangiato / mangiare / mangio] -> mangiato :: -are → -ato: mangiato.
  Q2: Konuştun mu? Hai ___? (parlare) [parlato / parlare / parli] -> parlato :: -are → -ato: parlato.
  Q3: Uyuduk: Abbiamo ___ (dormire). [dormito / dormire / dormo] -> dormito :: -ire → -ito: dormito.
  Q4: -are fiilinin geçmiş ortacı hangi ekle biter? [-ato / -uto / -ito] -> -ato :: -are → -ato.
  Q5: Ekmek aldım: Ho ___ il pane. (comprare) [comprato / compruto / comprito] -> comprato :: -are → -ato: comprato.
  Q6: Anladın mı? Hai ___? (capire) [capito / caputo / capato] -> capito :: -ire → -ito: capito.
  Q7: Onlar çok çalıştı: ___ lavorato molto. [Hanno / Sono / Avete] -> Hanno :: loro + avere: hanno lavorato.

rule: essere (sono/sei/è/siamo/siete/sono) + ortaç. Erkek: <b>-o</b>, kadın: <b>-a</b>. "Sono andato" (erkek), "Sono andata" (kadın) = "gittim".

  ex: Sono andata a casa. = Eve gittim (kadın).
  ex: Lei è arrivata. = O geldi (kadın).
  ex: Siamo andati al bar. = Bara gittik.
  Q1: Eve gittim (kadın): Sono ___ a casa. (andare) [andata / andato / andare] -> andata :: Kadın için -a: andata.
  Q2: Hareket fiilleri passato prossimo'da hangi yardımcıyı alır? [essere / avere / fare] -> essere :: Hareket/durum: essere.
  Q3: O geldi (kadın): Lei ___ arrivata. [è / ha / hai] -> è :: essere: è.
  Q4: Bara gittik: ___ andati al bar. [Siamo / Abbiamo / Avete] -> Siamo :: noi + essere: siamo.
  Q5: O (erkek) geldi: Lui è ___. [arrivato / arrivata / arrivati] -> arrivato :: Erkek tekil: -o → arrivato.
  Q6: Evdeydim (kadın): Sono ___ a casa. (stare) [stata / stato / state] -> stata :: stare → stato/stata. Kadın: stata.
  Q7: Kızlar İtalya'ya gitti: Le ragazze sono ___ in Italia. [andate / andati / andata] -> andate :: Dişil çoğul: -e → andate.

=== it3-4 [grammar] Gramer: Modal fiiller (potere / volere)
intro: '-ebilmek' ve 'istemek' anlamı: potere (yapabilmek) ve volere (istemek). Sonrasında fiil yalın (mastar) gelir.
rule: potere: <b>posso, puoi, può, possiamo, potete, possono</b>. volere: <b>voglio, vuoi, vuole, vogliamo, volete, vogliono</b>. "Voglio un caffè" = "Bir kahve istiyorum".
structure: [["Özne","potere","volere"],["io","posso","voglio"],["tu","puoi","vuoi"],["lui/lei","può","vuole"],["noi","possiamo","vogliamo"]]
  ex: Voglio un caffè. = Bir kahve istiyorum.
  ex: Posso aiutarti. = Sana yardım edebilirim.
  ex: Puoi ripetere? = Tekrar eder misin?
  Q1: Bir kahve istiyorum: ___ un caffè. [Voglio / Posso / Vuoi] -> Voglio :: io istemek: voglio.
  Q2: Sana yardım edebilirim: ___ aiutarti. [Posso / Voglio / Puoi] -> Posso :: io yapabilmek: posso.
  Q3: Tekrar eder misin? ___ ripetere? [Puoi / Posso / Vuole] -> Puoi :: tu yapabilmek: puoi.
  Q4: İstiyoruz: ___ (volere, noi) [vogliamo / volete / vogliono] -> vogliamo :: noi: vogliamo.
  Q5: O gelebilir: Lei ___ venire. [può / posso / puoi] -> può :: lui/lei yapabilmek: può.
  Q6: Ne istiyorsun? Cosa ___? [vuoi / voglio / vuole] -> vuoi :: tu istemek: vuoi.
  Q7: Onlar gelemez: Loro non ___ venire. [possono / potete / possiamo] -> possono :: loro yapabilmek: possono.

=== it3-5 [grammar] Gramer: Sıfat uyumu (bello/bella)
intro: Sıfatlar, tanımladıkları ismin cinsiyet ve sayısına uyar.
rule: Eril tekil <b>-o</b>, dişil tekil <b>-a</b>, eril çoğul <b>-i</b>, dişil çoğul <b>-e</b>: bello, bella, belli, belle.
structure: [["","Tekil","Çoğul"],["Eril","bello","belli"],["Dişil","bella","belle"]]
  ex: un ragazzo bello = yakışıklı bir çocuk
  ex: una casa bella = güzel bir ev
  ex: case belle = güzel evler
  Q1: güzel bir ev (dişil tekil): una casa ___ [bella / bello / belle] -> bella :: Dişil tekil: -a.
  Q2: yakışıklı çocuk (eril tekil): un ragazzo ___ [bello / bella / belli] -> bello :: Eril tekil: -o.
  Q3: güzel evler (dişil çoğul): case ___ [belle / belli / bella] -> belle :: Dişil çoğul: -e.
  Q4: güzel çocuklar (eril çoğul): ragazzi ___ [belli / belle / bello] -> belli :: Eril çoğul: -i.
  Q5: kırmızı bir sandalye: una sedia ___ [rossa / rosso / rosse] -> rossa :: sedia dişil tekil: rossa.
  Q6: Yorgunum (kadın): Sono ___. [stanca / stanco / stanchi] -> stanca :: Kadın konuşuyor: dişil tekil -a → stanca.
  Q7: beyaz kitaplar: libri ___ [bianchi / bianche / bianco] -> bianchi :: Eril çoğul -i; sesi korumak için h eklenir: bianchi.

=== it3-6 [grammar] Gramer: Karşılaştırma (più ... di)
intro: İki şeyi karşılaştırırken 'più ... di' (daha ... -den) kullanılır.
rule: <b>più</b> + sıfat + <b>di</b>: "Roma è più grande di Pisa" = "Roma Pisa'dan daha büyük". Daha az için <b>meno</b>. (di + il = <b>del</b>: più forte del tè.)
structure: [["Yapı","Örnek"],["più ... di","più grande di"],["meno ... di","meno caro di"]]
  ex: Roma è più grande di Pisa. = Roma Pisa'dan daha büyük.
  ex: Il caffè è più forte del tè. = Kahve çaydan daha sert.
  Q1: daha büyük: ___ grande [più / meno / molto] -> più :: daha = più.
  Q2: Roma Pisa'dan daha büyük: Roma è più grande ___ Pisa. [di / da / a] -> di :: karşılaştırmada -den = di.
  Q3: daha az pahalı: ___ caro [meno / più / tanto] -> meno :: daha az = meno.
  Q4: Kahve çaydan daha sert: Il caffè è più forte ___ tè. [del / di / dal] -> del :: di + il = del: del tè.
  Q5: Tren otobüsten daha hızlı: Il treno è ___ veloce dell'autobus. [più / meno / tanto] -> più :: daha = più.
  Q6: Pisa Roma'dan daha küçük (daha az büyük): Pisa è ___ grande di Roma. [meno / più / molto] -> meno :: daha az = meno.

=== it3-10 [grammar] Gramer: Dönüşlü fiiller (mi alzo, mi chiamo)
intro: Kişinin kendine yaptığı işler için dönüşlü fiiller kullanılır: kalkmak, yıkanmak, giyinmek. 'Mi chiamo' da dönüşlüdür.
rule: Fiilin önüne <b>mi, ti, si, ci, vi, si</b> gelir. alzarsi (kalkmak): io <b>mi alzo</b>, tu <b>ti alzi</b>, lui/lei <b>si alza</b>, noi <b>ci alziamo</b>, voi <b>vi alzate</b>, loro <b>si alzano</b>.
structure: [["Özne","Zamir","alzarsi"],["io","mi","mi alzo"],["tu","ti","ti alzi"],["lui/lei","si","si alza"],["noi","ci","ci alziamo"],["voi","vi","vi alzate"],["loro","si","si alzano"]]
  ex: Mi alzo alle sette. = Saat yedide kalkarım.
  ex: Come ti chiami? = Adın ne?
  ex: Lei si sveglia presto. = O erken uyanır.
  ex: Ci vestiamo e usciamo. = Giyinip çıkıyoruz.
  Q1: Saat yedide kalkarım: ___ alzo alle sette. [Mi / Ti / Si] -> Mi :: io → mi: mi alzo.
  Q2: Adın ne? Come ___ chiami? [ti / mi / si] -> ti :: tu → ti: ti chiami.
  Q3: O (kadın) sekizde uyanır: Lei ___ sveglia alle otto. [si / mi / ci] -> si :: lui/lei → si: si sveglia.
  Q4: Biz giyiniriz: Noi ___ vestiamo. [ci / vi / si] -> ci :: noi → ci: ci vestiamo.
  Q5: Onun adı Marco: ___ chiama Marco. [Si / Mi / Ti] -> Si :: lui → si: si chiama.
  Q6: Ellerimi yıkarım: Mi ___ le mani. (lavarsi) [lavo / lava / lavi] -> lavo :: io → mi lavo.
  Q7: Nasıl hissediyorsun? Come ti ___? (sentirsi) [senti / sento / sente] -> senti :: tu → ti senti.

=== it3-13 [grammar] Gramer: Birleşik edatlar (al, nel, del...)
intro: a, di, da, in, su edatları 'il / la / l'' ile birleşip tek kelime olur. Günlük konuşmada çok sık çıkar.
rule: a + il = <b>al</b>, a + la = <b>alla</b>, di + il = <b>del</b>, in + il = <b>nel</b>, in + la = <b>nella</b>, da + il = <b>dal</b>, su + il = <b>sul</b>. Sesli harften önce: <b>all', dell', nell', dall', sull'</b>. <b>da</b> birinin yanına gitmek için de kullanılır: vado dal medico.
structure: [["Edat","+ il","+ la","+ l'"],["a","al","alla","all'"],["di","del","della","dell'"],["in","nel","nella","nell'"],["da","dal","dalla","dall'"],["su","sul","sulla","sull'"]]
  ex: Vado al bar. = Bara gidiyorum.
  ex: Sono all'aeroporto. = Havalimanındayım.
  ex: Il latte è nel frigorifero. = Süt buzdolabında.
  ex: Vado dal medico. = Doktora gidiyorum.
  Q1: Bara gidiyorum: Vado ___ bar. [al / alla / allo] -> al :: a + il = al.
  Q2: Kitap çantanın içinde: Il libro è ___ borsa. [nella / nel / nello] -> nella :: in + la = nella (borsa dişil).
  Q3: Havalimanındayım: Sono ___ aeroporto. [all' / al / alla] -> all' :: a + l' = all' (sesli harften önce).
  Q4: Doktora gidiyorum: Vado ___ medico. [dal / dalla / del] -> dal :: Birinin yanına: da + il = dal.
  Q5: Kedi yatağın üstünde: Il gatto è ___ letto. [sul / sulla / nel] -> sul :: üstünde: su + il = sul.
  Q6: Kızın evi: La casa ___ ragazza. [della / del / dalla] -> della :: -in (sahiplik): di + la = della.
  Q7: İstasyona gidiyorum: Vado ___ stazione. [alla / al / nella] -> alla :: a + la = alla (stazione dişil).

=== it4-2 [grammar] Gramer: Geçmişte süreklilik (imperfetto)
intro: Imperfetto, geçmişteki alışkanlıkları, tasvirleri ve devam eden durumları anlatır. Türkçedeki '-ardı / -iyordu' gibidir.
rule: Mastarın sonundaki -re atılır, <b>-vo, -vi, -va, -vamo, -vate, -vano</b> eklenir: parlare → <b>parlavo</b>, avere → <b>avevo</b>, dormire → <b>dormivo</b>. Düzensiz: essere → <b>ero, eri, era, eravamo, eravate, erano</b>; fare → <b>facevo</b>.
structure: [["Özne","parlare","essere"],["io","parlavo","ero"],["tu","parlavi","eri"],["lui/lei","parlava","era"],["noi","parlavamo","eravamo"],["voi","parlavate","eravate"],["loro","parlavano","erano"]]
  ex: Da bambina giocavo in giardino. = Çocukken bahçede oynardım.
  ex: Era una bella giornata. = Güzel bir gündü.
  ex: Mia madre faceva il pane. = Annem ekmek yapardı.
  ex: Avevamo un cane. = Bir köpeğimiz vardı.
  Q1: Çocukken çok oynardım: Da bambina ___ molto. (giocare) [giocavo / giocava / giocavamo] -> giocavo :: io → -vo: giocavo.
  Q2: Annem hep ekmek yapardı: Mia madre ___ sempre il pane. (fare) [faceva / facevo / facevano] -> faceva :: fare düzensiz: facevo, facevi, faceva...
  Q3: Güzel bir gündü: ___ una bella giornata. (essere) [Era / Ero / Eri] -> Era :: Tasvir, 3. tekil: era.
  Q4: Sen hep yorgundun: Tu ___ sempre stanca. (essere) [eri / era / ero] -> eri :: tu → eri.
  Q5: Onların bir köpeği vardı: Loro ___ un cane. (avere) [avevano / avevamo / aveva] -> avevano :: loro → -vano: avevano.
  Q6: Her akşam televizyon izlerdim: ___ la TV ogni sera. (guardare) [Guardavo / Guardava / Guardato] -> Guardavo :: Alışkanlık, io → guardavo.
  Q7: Gençken İstanbul'da otururduk: Da giovani ___ a Istanbul. (abitare) [abitavamo / abitavano / abitavate] -> abitavamo :: noi → -vamo: abitavamo.
  Q8: Imperfetto hangi durumda kullanılır? [Geçmişteki alışkanlıklar / Gelecek planları / Emir vermek] -> Geçmişteki alışkanlıklar :: Imperfetto: geçmişteki alışkanlık, tasvir ve süreklilik.

=== it4-4 [grammar] Gramer: Imperfetto mi, passato prossimo mu?
intro: İki geçmiş zaman birlikte kullanılır: biri 'sahneyi', diğeri 'olayı' anlatır.

  ex: L'anno scorso sono andata a Roma. = Geçen yıl Roma'ya gittim.

  Q3: Ben yemek yaparken telefon çaldı: Mentre ___, ha squillato il telefono. [cucinavo / ho cucinato / cucinerò] -> cucinavo :: mentre + arka plandaki eylem: imperfetto.
  Q4: Kitap okuyordum, birden telefon çaldı: Leggevo un libro quando all'improvviso ___ il telefono. [ha squillato / squillava / squillerà] -> ha squillato :: Birden olan tek olay: passato prossimo.
  Q5: Küçükken saçlarım uzundu: Quando ero piccola, ___ i capelli lunghi. [avevo / ho avuto / avrò] -> avevo :: Geçmişteki tasvir: imperfetto.
  Q6: Geçen yıl bir haftalığına Roma'ya gittim (kadın): L'anno scorso ___ a Roma per una settimana. [sono andata / andavo / vado] -> sono andata :: Sınırlı süre, bitmiş olay: passato prossimo.
  Q7: Bir kez olup biten olay için hangisi? [Passato prossimo / Imperfetto / Futuro] -> Passato prossimo :: Tek, bitmiş olay: passato prossimo.
  Q8: Hava, saat, yaş gibi arka plan tasviri için hangisi? [Imperfetto / Passato prossimo / Futuro] -> Imperfetto :: Tasvir ve arka plan: imperfetto.

=== it4-6 [grammar] Gramer: Gelecek zaman — düzensiz fiiller
intro: Futuro'da en sık kullanılan fiillerin bir kısmı düzensizdir. Ekler aynıdır (-ò, -ai, -à, -emo, -ete, -anno), sadece kök değişir.

  ex: Quest'estate andremo in Italia. = Bu yaz İtalya'ya gideceğiz.
  ex: Verrò da te sabato. = Cumartesi sana geleceğim.
  ex: Ci vedremo presto! = Yakında görüşeceğiz!

  Q2: Gelecek hafta vaktim olacak: La settimana prossima ___ tempo. (avere) [avrò / averò / ho] -> avrò :: avere → avrò (e düşer).
  Q3: Bu yaz İtalya'ya gideceğiz: Quest'estate ___ in Italia. (andare) [andremo / anderemo / andiamo] -> andremo :: andare → andremo (noi).
  Q4: Akşam alışveriş yapacağım: Stasera ___ la spesa. (fare – futuro) [farò / farerò / faccio] -> farò :: fare → farò.
  Q5: Cumartesi sana geleceğim: Sabato ___ da te. (venire – futuro) [verrò / venirò / vengo] -> verrò :: venire → verrò (çift r).
  Q6: Yakında görüşeceğiz: Ci ___ presto! (vedere – futuro) [vedremo / vederemo / vediamo] -> vedremo :: vedere → vedremo.
  Q7: Mutlu olacaksın: Tu ___ contenta. (essere – futuro) [sarai / sarà / sei] -> sarai :: tu → sarai.

=== it4-7 [grammar] Gramer: Kibar rica (vorrei, potrebbe)
intro: Condizionale (şart kipi) ile rica ve istekler daha kibar olur. Dükkânda, restoranda, otelde her gün lazım.

  ex: Vorremmo un tavolo per due. = İki kişilik bir masa istiyoruz.
  Q1: Kibarca bir kahve iste: ___ un caffè, per favore. [Vorrei / Vorrò / Vuole] -> Vorrei :: Kibar istek: vorrei.
  Q2: Bana yardım edebilir misiniz? (resmi): ___ aiutarmi? [Potrebbe / Potrei / Potremmo] -> Potrebbe :: Resmi 'siz' (Lei) → potrebbe.
  Q3: Pencereyi açabilir miyim? ___ aprire la finestra? [Potrei / Potrebbe / Potresti] -> Potrei :: io → potrei.
  Q4: Roma'yı görmek çok hoşuma giderdi: Mi ___ vedere Roma. [piacerebbe / piace / piacciono] -> piacerebbe :: '-ardı' anlamı: mi piacerebbe.
  Q5: İki kişilik bir masa isterdik: ___ un tavolo per due. [Vorremmo / Vorrei / Vorreste] -> Vorremmo :: noi → vorremmo.
  Q6: Doktora gitmelisin: ___ andare dal medico. [Dovresti / Dovrei / Dovrebbero] -> Dovresti :: tu → dovresti (tavsiye).
  Q7: Condizionale di cortesia ne işe yarar? [Kibar rica ve istek / Geçmişi anlatmak / Emir vermek] -> Kibar rica ve istek :: Vorrei, potrebbe... ricayı kibarlaştırır.

=== it4-9 [grammar] Gramer: Nesne zamirleri (lo / la / li / le)
intro: Bir ismi tekrar etmemek için 'onu / onları' anlamında nesne zamiri kullanılır.
rule: <b>lo</b> = onu (eril), <b>la</b> = onu (dişil), <b>li</b> = onları (eril), <b>le</b> = onları (dişil). Ayrıca <b>mi</b> (beni), <b>ti</b> (seni), <b>ci</b> (bizi), <b>vi</b> (sizi). Zamir çekimli fiilden <b>önce</b> gelir: "Il caffè? <b>Lo</b> bevo." = Kahve mi? Onu içerim.

  ex: Il caffè? Lo bevo ogni mattina. = Kahve mi? Onu her sabah içerim.
  ex: Maria? Sì, la conosco. = Maria mı? Evet, onu tanıyorum.
  ex: Ti chiamo domani. = Seni yarın ararım.
  Q1: Kahve mi? Onu her sabah içerim: Il caffè? ___ bevo ogni mattina. [Lo / La / Li] -> Lo :: caffè eril tekil → lo.
  Q2: Pizza mı? Onu bu akşam yerim: La pizza? ___ mangio stasera. [La / Lo / Le] -> La :: pizza dişil tekil → la.
  Q3: Bisküviler mi? Onları süpermarketten alırım: I biscotti? ___ compro al supermercato. [Li / Le / Lo] -> Li :: biscotti eril çoğul → li.
  Q4: Elmalar mı? Onları ben alırım: Le mele? ___ prendo io. [Le / Li / La] -> Le :: mele dişil çoğul → le.
  Q5: Maria mı? Evet, onu tanıyorum: Maria? Sì, ___ conosco. [la / lo / li] -> la :: Maria kadın → la.
  Q6: Beni duyuyor musun? ___ senti? [Mi / Ti / Ci] -> Mi :: beni = mi.
  Q7: Seni yarın ararım: ___ chiamo domani. [Ti / Mi / Vi] -> Ti :: seni = ti.
  Q8: Nesne zamiri çekimli fiile göre nereye gelir? [Fiilden önce / Fiilden sonra / Cümlenin sonuna] -> Fiilden önce :: Lo bevo, la conosco: zamir fiilden önce.

=== it4-10 [grammar] Gramer: Birleşik zamirler (me lo, glielo)
intro: 'Onu bana', 'onu sana', 'onu ona' demek için iki zamir birleşir. Başlangıç için en sık kalıpları öğrenelim.
rule: mi → <b>me</b>, ti → <b>te</b>, ci → <b>ce</b>, vi → <b>ve</b> olur ve lo/la'nın önüne gelir: <b>me lo</b>, <b>te la</b>, <b>ce lo</b>. 'Ona' (gli / le) + lo/la → tek kelime: <b>glielo</b>, <b>gliela</b>. "<b>Me lo</b> dai?" = Onu bana verir misin?

  ex: Il libro? Me lo dai? = Kitap mı? Onu bana verir misin?
  ex: Il caffè? Te lo porto io. = Kahve mi? Onu sana ben getiririm.
  ex: La verità? Gliela dico domani. = Gerçek mi? Onu ona yarın söylerim.
  Q1: Kitabı bana verir misin? Il libro? ___ dai? [Me lo / Mi lo / Lo me] -> Me lo :: mi → me + lo: me lo.

  Q3: Onu ona (erkeğe) söylerim: ___ dico. [Glielo / Gli lo / Lo gli] -> Glielo :: gli + lo = glielo (tek kelime).
  Q4: Onu ona (kadına) söylerim: ___ dico. [Glielo / Le lo / Lo le] -> Glielo :: le + lo da glielo olur.
  Q5: Pizzayı sana ben getiririm: La pizza? ___ porto io. [Te la / Te lo / Ti la] -> Te la :: pizza dişil: te + la = te la.
  Q6: mi + lo birleşince ne olur? [me lo / mi lo / lo mi] -> me lo :: mi → me olur: me lo.
  Q7: Anahtarı bize verir misin? La chiave? ___ dai? [Ce la / Ci la / Ce lo] -> Ce la :: ci → ce; chiave dişil → la: ce la.

=== it4-12 [grammar] Gramer: En üstünlük (il più, -issimo, migliore)
intro: 'En ...' ve 'çok çok ...' demenin yolları, ayrıca buono ve bene'nin özel biçimleri.
rule: En: <b>il/la più</b> + sıfat (+ di): "la città <b>più</b> bella d'Italia". Çok çok: sıfat + <b>-issimo</b>: bello → <b>bellissimo</b>, buona → <b>buonissima</b>. Özel: buono → <b>migliore</b> (daha iyi), cattivo → <b>peggiore</b> (daha kötü), bene → <b>meglio</b> (zarf). Eşitlik: <b>come</b> (kadar).
structure: [["Yapı","Anlam","Örnek"],["il/la più ...","en ...","la città più bella"],["-issimo / -issima","çok çok ...","bellissimo, buonissima"],["migliore / peggiore","daha iyi / daha kötü","un caffè migliore"],["meglio","daha iyi (zarf)","parla meglio"],["come","... kadar","alta come me"]]
  ex: Roma è la città più grande d'Italia. = Roma İtalya'nın en büyük şehri.
  ex: Questa pizza è buonissima! = Bu pizza çok çok lezzetli!
  ex: Lei parla meglio di me. = O benden daha iyi konuşuyor.
  Q1: Roma İtalya'nın en büyük şehri: Roma è la città ___ grande d'Italia. [più / meno / molto] -> più :: en = il/la più.
  Q2: Çok çok güzel: bello → ___ [bellissimo / bellosissimo / più bello] -> bellissimo :: Son ünlü düşer + -issimo: bellissimo.
  Q3: Bu pizza çok çok lezzetli: Questa pizza è ___. [buonissima / buonissimo / buonissime] -> buonissima :: pizza dişil tekil: buonissima.
  Q4: Bu kahve ötekinden daha iyi: Questo caffè è ___ di quello. [migliore / peggiore / meglio] -> migliore :: buono → migliore (sıfat).
  Q5: Bu şarap ötekinden daha kötü: Questo vino è ___ di quello. [peggiore / migliore / meglio] -> peggiore :: cattivo → peggiore (daha kötü).
  Q6: O benden daha iyi konuşuyor: Lei parla ___ di me. [meglio / migliore / peggiore] -> meglio :: Fiili niteliyor (zarf): bene → meglio.
  Q7: O benim kadar uzun: Lei è alta ___ me. [come / di / che] -> come :: Eşitlik: come (kadar).
