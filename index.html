    Cihazlar arası senkron

    Bilgisayar, telefon ve tablet aynı ilerlemeyi gösterir; kayıtlar GitHub hesabındaki gizli bir Gist'te birleşir.

    Kapalı
    Token nasıl alınır?
    1. github.com'a gir → sağ üstte profil resmi → Settings.
    2. Sol menünün en altı: Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    3. Token name: TY Dil
    4. Expiration: listedeki en uzun süreyi seç. Süresi dolunca yenisini oluşturup buraya yapıştır.
    5. Repository access: Public repositories
    6. Permissions → Account permissions → Gists → Read and write
    7. Generate token → çıkan kodu kopyala (github_pat_ ile başlar), yukarıya yapıştır, Bağla.
    Token sayfasını aç ↗

    Otomatik çalışır: açılışta, uygulamaya dönünce ve her kayıttan kısa süre sonra. Claude anahtarı ve GitHub token'ı senkrona girmez; her cihazda yerel kalır.

    Yedek

    Senkron kapalıysa kayıtların yalnızca bu cihazda durur. Telefon değiştirmeden ya da tarayıcı verisini silmeden önce yedek al; başka cihazda geri yükle.
